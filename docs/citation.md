# Citing SeroRef

If you use **SeroRef** in your research, bacterial antigen locus discovery, or publications, please cite the software using the metadata below.

=== "BibTeX"

    ```bibtex
    @software{Stanton_SeroRef,
      author       = {Stanton, Thomas David},
      title        = {{SeroRef: De novo bacterial surface polysaccharide locus prediction, 1D-CNN gene role classification, and Strain-Assembly-Locus reference database}},
      url          = {https://seroverse.github.io/SeroRef/},
      repository   = {https://github.com/SeroVerse/SeroRef},
      license      = {GPL-3.0-only}
    }
    ```

=== "APA"

    ```text
    Stanton, T. D. SeroRef: De novo bacterial surface polysaccharide locus prediction, 1D-CNN gene role classification, and Strain–Assembly–Locus reference database [Computer software]. https://github.com/SeroVerse/SeroRef
    ```
